# Обёртка над Keitaro

Тестовое задание «Это Легко»: веб-обёртка над рекламным трекером Keitaro.

- **Часть 1. Создаватор кампаний.** Форма: название, гео (коды стран через запятую),
  оффер с автокомплитом. По кнопке Create в Keitaro создаётся кампания
  с группой, доменом и источником и двумя потоками:
  первый ловит трафик из указанных стран и редиректит на google.com,
  второй отправляет остальных на выбранный оффер.
- **Часть 2. Редактор офферов.** Список кампаний и потоков, синхронизация
  из Keitaro (FETCH), добавление/удаление офферов с пересчётом весов,
  закрепление веса (pin), публикация изменений (PUSH TO KT) и отмена (CANCEL),
  возврат удалённых (BRING BACK), включая офферы, удалённые прямо в Keitaro.

Стек: FastAPI + SQLAlchemy (SQLite по умолчанию, PostgreSQL подставляется URL),
фронт — vanilla HTML/JS без сборки. Разработка велась с ИИ-агентом.

## Запуск

Нужен Python 3.10+.

```
python -m venv .venv
.venv\Scripts\activate            # Windows (bash: source .venv/Scripts/activate)
pip install -r requirements.txt
```

Создать `.env` рядом с проектом (образец `.env.example`):

```
KEITARO_API_KEY=<ключ из Keitaro: Профиль → API ключи → Создать новый ключ>
KEITARO_BASE_URL=https://tlgk.host
```

Миграции и запуск:

```
alembic upgrade head
uvicorn app.main:app --port 8010
```

Открыть http://127.0.0.1:8010

## Миграции

Alembic, единственная начальная ревизия создаёт таблицы
`campaigns`, `streams`, `stream_offers`.

```
alembic upgrade head      # применить
alembic revision --autogenerate -m "описание"   # новая миграция при изменении моделей
```

URL базы берётся из `DATABASE_URL` (.env), по умолчанию SQLite `wrapper.db`.
Для PostgreSQL: `DATABASE_URL=postgresql+psycopg2://user:pass@host/db`.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `KEITARO_API_KEY` | ключ Admin API (обязательно) | — |
| `KEITARO_BASE_URL` | адрес трекера | `https://tlgk.host` |
| `DATABASE_URL` | строка подключения к БД | SQLite `wrapper.db` |
| `KEITARO_GROUP_NAME` | группа новых кампаний | `VZ adrobot test` |
| `CAMPAIGN_NAME_PREFIX` | префикс имён кампаний | `test_chizhov_` |

## Как устроено

- `app/keitaro_api.py` — тонкий клиент Admin API (Bearer-ключ, base `/admin_api/v1`).
  Формат потоков выверен по живым данным трекера: URL redirect-потока
  передаётся строкой в `action_payload`, `action_type: http` обязателен обоим схемам,
  фильтр страны — `{name: country, mode: accept, payload: [коды]}`.
- `app/models.py` — локальное зеркало: кампании/потоки/офферы. Локальная база
  нужна ради того, чего нет в Keitaro: несохранённые изменения (жёлтый поток),
  удалённые офферы со статусом removed и Bring Back, закреплённые веса.
- `app/weights.py` — пересчёт долей: активные делят 100%, запиненный вес заморожен,
  остаток делится поровну с добором последнему до ровных 100. Покрыт тестами.
- `app/main.py` — ручки: создание кампании с двумя потоками, fetch/push/cancel,
  add/remove/restore/pin офферов, поиск офферов с автокомплитом (кеш 173 записи).
- `static/index.html` — редактор: список кампаний и потоки, жёлтая подсветка
  несохранённых изменений, как в видео заказчика.
- `static/create.html` — создаватор кампаний: отдельная страница с формой
  (название, гео, оффер с автокомплитом); после Create возвращает к кампаниям.

### Известное ограничение тестового стенда

Выданный API-ключ не имеет прав на создание доменов и источников
(403 на `POST /domains`, `POST /traffic_sources`; у всех кампаний кандидатов
в этом стенде `traffic_source_id=0`, `domain=null`). Обёртка пробует настроить
домен и источник, при отказе прав кампания создаётся с группой `VZ adrobot test`
и доменом трекера по умолчанию — ровно как в кампаниях-референсах заказчика.

## Тесты

```
pytest tests/ -q
```

5 тестов на пересчёт весов: равное деление, сумма 100%, обнуление удалённых,
заморозка запиненных, пин при добавлении/удалении.
